2. Data Collected

The following personal data is processed when using Game-Log Pro:

  • Username — for identification within the app.
  • Email Address (optional) — only stored if provided during registration.
  • Password — is never stored in plaintext, but exclusively as an irreversible hash (Bcrypt).
  • Game Statistics — played sessions, scores, winners, timer data, and optional comments.
  • Photos (optional) — uploaded images of game sessions are stored on the server.
  • Server Logs — IP addresses and timestamps are recorded in server logs for technical reasons.

3. Purpose of Processing

The data is used exclusively to provide the board game group tracker and its associated statistics. No data is shared with third parties.

4. Hosting & Server Location

The app and all data are hosted on a private server (Location: Germany/EU). The connection is encrypted via HTTPS (TLS).

5. Cookies & Tracking

Game-Log Pro uses no cookies and no tracking (no Google Analytics, no Facebook Pixel, etc.). Authentication is based on a JWT token that is stored exclusively in the browser's localStorage. This is technically necessary and requires no cookie banner.

6. Your Rights (GDPR Art. 15–21)

You have the right to:

  • Information (Art. 15) — what data is stored about you.
  • Rectification (Art. 16) — correction of incorrect data (e.g., changing username in account settings).
  • Erasure (Art. 17, "Right to be forgotten") — you can permanently delete your account at any time directly in the app under 👤 → ⚠️ Delete Account. This completely removes all your game results, statistics, group memberships, and uploaded photos from the server.
  • Data Portability (Art. 20) — you can download all your stored data (profile, groups, game results) at any time in the app under ⚙️ Manage Account ➔ 📥 Export My Data as a JSON file.

7. Data Security

  • Passwords are hashed using Bcrypt (automatic salting, high work factor).
  • API access is secured via JWT tokens (HS256, 30 days validity).
  • The server receives regular security updates.
  • The database is backed up and encrypted.

8. Changes to this Privacy Policy

We reserve the right to adapt this privacy policy if necessary, e.g., when extending app functionality. The current version is always available at this URL.

If you have any questions regarding data protection, please contact the responsible party via email.
